# Vehicle Fundamentals

Симуляция физики автомобиля для Unity с использованием raycast-колёс. Реализована на C# на основе документации [Vehicle Fundamentals](https://vehicle-fundamentals.prototypeeverything.com/) от Prototype Everything.

[English](README.md)

## Требования

- Unity **6000.6.8f1**.
- Git LFS для моделей, текстур и подготовленных мешей.
- URP, Input System, Cinemachine и uGUI. Версии пакетов закреплены в [Packages/manifest.json](Packages/manifest.json).

## Быстрый запуск

1. Клонируйте репозиторий и загрузите LFS-ассеты:

   ```sh
   git lfs install
   git lfs pull
   ```

2. Откройте проект в Unity Hub и дождитесь импорта ассетов.
3. Откройте `Assets/VehicleFundamentals/Scenes/PhysicsSandbox.unity` и нажмите **Play**.

## Возможности

- Raycast-подвеска: пружины, демпферы, стабилизаторы и нагрузка на колёса, определяемая движением Rigidbody.
- Кривые сцепления шин, комбинированное скольжение, круг сцепления, инерция колёс и сопротивление качению.
- ДВС и электропривод, автоматическое переключение передач, задний ход, открытые и самоблокирующиеся дифференциалы.
- Рулевая геометрия Аккермана, противобуксовочная система, ABS, ассисты дрифта и контрруления.
- Многоосные автомобили, движущиеся поверхности и аэродинамическое сопротивление.
- Тестовая сцена с выбором автомобиля, внешней и капотной камерами, следами шин и дымом.
- Телеметрический HUD на Canvas / TextMeshPro с опорным разрешением **2560 × 1440**.

## Настройка автомобиля

Продублируйте ассет из `Assets/VehicleFundamentals/Definitions` или создайте новый через **Assets → Create → Vehicle Fundamentals → Vehicle Definition**. Назначьте его в `RaycastVehicleController → Definition`.

Определение содержит настройки массы, центра масс, геометрии осей, подвески, шин, тормозов и трансмиссии. Степень вмешательства ассистов задаётся в диапазоне от 0 до 1. Для применения изменений в Play Mode используйте пункт **Rebuild Vehicle** в контекстном меню контроллера.

Чтобы использовать автомобиль в другой сцене, добавьте `RaycastVehicleController` и `VehiclePlayerInput` на объект с `Rigidbody`. Добавьте компоненты визуализации или используйте готовую конфигурацию из тестовой сцены. Собственные источники ввода должны реализовывать `IVehicleInputSource`.

## Структура кода

Код и ассеты проекта находятся в `Assets/VehicleFundamentals/`.

| Каталог | Назначение |
| --- | --- |
| Runtime/Core | Математика, настройки, кривые и интерфейс `IPhysicsWorld` |
| Runtime/Vehicle | Симуляция автомобиля, осей, колёс, руля и педалей |
| Runtime/Drivetrain | ДВС и электропривод |
| Runtime/Data | Данные `VehicleDefinition` |
| Runtime/Unity | Адаптер Rigidbody, ввод, визуализация, камеры и HUD |
| Definitions | Пресеты автомобилей |
| Editor | Инспектор определений автомобилей |
| Models | Исходные модели и подготовленные префабы |
| Scenes / Settings | Тестовая сцена и конфигурация URP |

Симуляция работает в `FixedUpdate` с частотой 50 Гц. Физическое ядро не зависит от Unity; адаптер движка — `UnityVehiclePhysics`. Используются единицы СИ. Локальные оси: +X — вправо, +Y — вверх, +Z — вперёд.

Формулы и порядок расчётов описаны в [полном референсе](https://vehicle-fundamentals.prototypeeverything.com/llms-full.txt). Соответствующие главы указаны в комментариях исходного кода.

## Хранение ассетов

Модели, текстуры и файлы `Models/Prepared/* Geometry.asset` хранятся через Git LFS. Сцены, префабы, материалы и файлы `.meta` — в обычном Git. Добавляйте файлы `.meta` в коммиты, чтобы сохранять ссылки на ассеты.

Для файлов Unity в формате YAML в `.gitattributes` указан атрибут `unityyamlmerge`. Настройте драйвер слияния Git для использования Smart Merge из установленной версии Unity.

## Ограничения

- Звук двигателя и деформация шин не реализованы.
- Столкновения шин с арками кузова не моделируются.
